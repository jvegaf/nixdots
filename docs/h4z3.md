# Host h4z3 - VirtualBox Testing Environment

## Overview

Host **h4z3** es un host de NixOS diseñado para pruebas en VirtualBox. Permite desarrollar y testear la configuración del flake en un entorno virtualizado antes de aplicarla al host principal (`fs0ciety`).

**Este host usa X11 + AwesomeWM** en lugar de Wayland + Hyprland (como fs0ciety).

## Quick Start

### 1. Construir imagen ISO

```bash
cd ~/Code/nix/nixdots
nix build .#nixosConfigurations.h4z3.config.system.build.isoImage
```

La ISO se generará en `result/iso/`

### 2. Crear VM en VirtualBox

1. Nueva máquina virtual:
   - **Nombre**: h4z3
   - **Tipo**: Linux
   - **Versión**: Other Linux (64-bit)
   - **RAM**: 4096 MB (mínimo 2048 MB)
   - **CPU**: 2 cores

2. Almacenamiento:
   - Disco duro: 20 GB (dinámico)
   - Controller SATA: agregar ISO generada en `result/iso/`

3. Red:
   - Adaptador 1: NAT (para acceso a internet)

4. Sistema:
   - Habilitar EFI (opcional)
   - IO APIC habilitado

### 3. Arrancar y configurar

1. Boot desde la ISO
2. Login como root (sin contraseña en el ISO minimal)
3. Ejecutar:
   ```bash
   mount /dev/sda1 /mnt
   nixos-install
   reboot
   ```

## Estructura de Archivos

```
hosts/h4z3/
├── configuration.nix           # Configuración principal del host
├── disko.nix                   # Configuración de disco (disko)
├── hardware-configuration.nix # Configuración de hardware (VirtualBox)
└── local-packages.nix          # Paquetes específicos del host
```

## Disko

El host h4z3 usa disko para particionar el disco de VirtualBox:

```nix
disko.devices = {
  disk = {
    main = {
      device = "/dev/sda";  # Disco SATA de VirtualBox
      content = {
        partitions = {
          boot = { start = "1MiB", end = "512MiB", type = "EF00" };
          root = { start = "512MiB", end = "100%" };
        };
      };
    };
  };
};
```

### Comandos para h4z3

```bash
# Formatear disco virtual
sudo disko --mode format --flake ~/Code/nix/nixdots#h4z3

# Instalar NixOS
sudo nixos-install --flake ~/Code/nix/nixdots#h4z3
```

### configuration.nix

```nix
{ pkgs, stateVersion, hostname, ... }:

{
  imports = [
    ./hardware-configuration.nix
    ./local-packages.nix
    ../../nixos/modules
  ];

  environment.systemPackages = [ pkgs.home-manager ];

  networking.hostName = hostname;

  system.stateVersion = stateVersion;
}
```

### hardware-configuration.nix

Configuración optimizada para VirtualBox:

| Módulo | Descripción |
|--------|-------------|
| `vboxguest` | Guest additions - permite coordenadas de mouse, carpetas compartidas |
| `vboxsf` | Shared folders - monta carpetas del host |
| `vboxvideo` | Drivers de video |

### local-packages.nix

Paquetes adicionales instalados en este host:

```nix
{ pkgs, ... }: {
  environment.systemPackages = with pkgs; [
    gcc
  ];
}
```

## Comandos Útiles

### Rebuild desde dentro de la VM

```bash
# Dentro de h4z3
sudo nixos-rebuild switch --flake /home/th3g3ntl3man/Code/nix/nixdots#h4z3
```

### Regenerar configuración de hardware

```bash
sudo nixos-generate-config
sudo nixos-install
```

###folder compartidas

Las shared folders de VirtualBox se montan manualmente:

```bash
# En la VM
sudo mkdir /mnt/host
sudo mount -t vboxsf nombre_carpeta_compartida /mnt/host
```

## Diferencias con fs0ciety

| Característica | fs0ciety | h4z3 |
|----------------|----------|------|
| Display Server | Wayland | X11 |
| Window Manager | Hyprland | AwesomeWM |
| Hardware | Laptop real | VirtualBox |
| GPU | Intel iGPU | VirtualBox GPU |
| Boot | EFI | BIOS/EFI |
| Paquetes | Completos | Mínimos (gcc) |
| Propósito | Uso diario | Testing |

## Troubleshooting

### La VM no bootea desde la ISO

1. Verificar que la ISO está correctamenteattachada
2. En Settings > Storage, asegurar que el orden de boot tiene la ISO primero
3. Probar deshabilitar EFI

### Error de分辨率

```bash
# En la VM
sudo systemctl restart display-manager
```

### No hay red

```bash
# Verificar configuración NAT
ip addr show
ping -c 3 8.8.8.8
```

### Slow performance

- Aumentar RAM a 4GB+
- Asignar más cores de CPU
- Instalar VirtualBox Guest Additions

## Actualizar configuración

1. Editar archivos en `hosts/h4z3/`
2. Rebuild:
   ```bash
   nix build .#nixosConfigurations.h4z3.config.system.build.toplevel
   # o
   nixos-rebuild build --flake .#h4z3
   ```
